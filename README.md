
# 📊 Analyse des bibliothèques de Paris
Projet réalisé avec un notebook Jupyter à partir des données de l’Open Data Paris.
Données : Ville de Paris Open Data
# 🚀 Objectifs
•	Étudier la répartition des postes publics dans les bibliothèques parisiennes
•	Identifier les bibliothèques les mieux équipées en ordinateurs
•	Explorer les corrélations entre disponibilité des ressources et emprunts de titres
# 🛠️ Outils utilisés
•	Python (pandas, matplotlib, seaborn)
•	Jupyter Notebook
# 📂 Contenu
•	bibliotheques_paris.ipynb : notebook complet contenant l’analyse et les visualisations
•	requirements.txt : liste des bibliothèques Python nécessaires pour exécuter le notebook
# 📌 Résultats principaux
•	Les bibliothèques mettent surtout l’accent sur les postes adultes et les catalogues
•	Une forte inégalité d’équipement : quelques grandes bibliothèques concentrent la majorité des ordinateurs
•	Le nombre d’exemplaires est le facteur le plus déterminant pour expliquer le nombre d’emprunts
